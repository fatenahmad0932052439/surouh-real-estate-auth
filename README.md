
# 🏢 Surouh Real Estate - Luxury Authentication Portal

A modern, responsive, and elegant authentication portal designed specifically for premium real estate platforms. It features a luxury dark theme (Navy Blue & Slate Gray with Champagne Gold accents), an animated 3D brand logo, and an integrated client-side backend system powered by `localStorage`.

---

## ✨ Features

- **Luxury Aesthetic**: Sophisticated color palette combining deep navy (`#0F172A`), slate gray (`#151E2E`), and soft gold accents (`#C5A880`).
- **Continuous 3D Logo Animation**: An architectural "S" letter emblem with a continuous 3D rotation and pulsing aura ring.
- **Client-Side Backend & Database**: 
  - Fully functional user registration and login system powered by `localStorage`.
  - Data persists across browser refreshes without requiring external database setup.
- **Smart Validation & Personalized Dashboard**:
  - Validates user credentials; prompts non-registered users to create an account first.
  - Successfully authenticated users are redirected to a personalized welcome view (*"Welcome, I am Faten"*).
- **Smooth Form Switching**: Seamless tab transition between Sign In and Sign Up without full-page reloads.
- **UX & Accessibility**:
  - Show/Hide password toggle.
  - Compact container sizing with zero horizontal scrolling.
  - Fully responsive on mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **HTML5**: Semantic and clean structure.
- **CSS3**: Custom design with CSS Variables, Flexbox, Keyframe Animations, and Backdrop Blur.
- **Vanilla JavaScript**: Zero dependencies; native DOM manipulation and `localStorage` mock backend.
- **Font Awesome**: Modern iconography.
- **Google Fonts**: Arabic & Latin typography (`Tajawal`).
